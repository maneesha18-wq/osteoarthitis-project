# KneeAI: Explainable Knee Osteoarthritis Grade Classification Using Deep Learning

[![Next.js](https://img.shields.io/badge/Frontend-Next.js%2014-black?logo=next.js)](https://nextjs.org/)
[![FastAPI](https://img.shields.io/badge/Backend-FastAPI-009688?logo=fastapi)](https://fastapi.tiangolo.com/)
[![TensorFlow](https://img.shields.io/badge/ML-TensorFlow%20%2F%20Keras-FF6F00?logo=tensorflow)](https://tensorflow.org/)
[![Grad-CAM](https://img.shields.io/badge/XAI-Grad--CAM-blue)](https://arxiv.org/abs/1610.02391)
[![Supabase](https://img.shields.io/badge/Database-Supabase%20Postgres-3ECF8E?logo=supabase)](https://supabase.com/)

A medical-research decision-support web application that classifies knee radiograph severity into five Kellgren–Lawrence (KL) grades (Grade 0 to Grade 4) and provides transparent visual explanations via Gradient-weighted Class Activation Mapping (Grad-CAM).

> **IMPORTANT MEDICAL & RESEARCH DISCLAIMER:**  
> KneeAI is an academic Data Science research major project designed strictly for educational and decision-support exploration. The predictions, probabilities, and Grad-CAM visualizations generated by this system are experimental and DO NOT constitute a clinical diagnosis or medical evaluation. Always consult a certified healthcare professional or radiologist for clinical decisions.

## 🏗 System Architecture

```mermaid
flowchart TD
    User([User / Clinician]) -->|Upload Knee X-Ray| FE[Next.js 14 Frontend]
    FE -->|Authenticate| SupaAuth[(Supabase Auth)]
    FE -->|POST /predict multipart/form-data| BE[FastAPI AI Backend]
    BE -->|Preprocess 224x224 / CLAHE| Prep[Preprocessing Engine]
    Prep -->|Tensor| Model[MobileNetV2 Transfer Learning Model]
    Model -->|Logits & Softmax| Pred[5-Class KL Probabilities]
    Model -->|Gradients to Conv Layer| GradCAM[Grad-CAM Generator]
    GradCAM -->|Heatmap & Overlay| Res[Prediction Response]
    BE -->|JSON + Base64 Heatmaps| FE
    FE -->|Store Metadata & Record| SupaDB[(Supabase PostgreSQL with RLS)]
    FE -->|Interactive Review & PDF Export| User
```

## 🚀 Quick Start Guide

### Prerequisites
- Node.js 18+ (tested on v22.21.0)
- Python 3.10+ (tested on v3.12.2)
- Git

### 1. Installation
Run setup for both frontend and backend:
```bash
# Install root orchestrator and frontend dependencies
npm install
cd frontend && npm install && cd ..

# Setup backend Python environment
cd backend
python -m venv venv
# On Windows:
.\venv\Scripts\activate
# On Linux/macOS:
# source venv/bin/activate
pip install -r requirements.txt
cd ..
```

### 2. Configure Environment
Copy `.env.example` to `.env` in the root and configure Supabase or use default local development variables:
```bash
cp .env.example .env
```

### 3. Run Development Servers Together
```bash
npm run dev
```
This orchestrates both:
- **Frontend:** [http://localhost:3000](http://localhost:3000)
- **Backend API:** [http://localhost:8000](http://localhost:8000) (Interactive Swagger Docs at [http://localhost:8000/docs](http://localhost:8000/docs))

## 📊 Kellgren–Lawrence (KL) Grading System

- **Grade 0 (None):** Normal knee joint, no features of osteoarthritis.
- **Grade 1 (Doubtful):** Doubtful joint space narrowing and possible osteophytic lipping.
- **Grade 2 (Mild):** Definite osteophytes and possible joint space narrowing.
- **Grade 3 (Moderate):** Multiple moderate osteophytes, definite joint space narrowing, some sclerosis, and possible deformity of bone ends.
- **Grade 4 (Severe):** Large osteophytes, marked joint space narrowing, severe sclerosis, and definite deformity of bone contour.
